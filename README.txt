BIRD BLAZE - GITHUB / GAMEDISTRIBUTION PACKAGE

Files required together in the same folder:
- index.html
- background.jpg
- eagle.png

IMPORTANT:
1. Keep the image filenames exactly as shown above. The HTML references background.jpg and eagle.png.
2. For GitHub Pages, upload all three files into the repository root (same folder as index.html), then commit.
3. GameDistribution rewarded ads require your real Game ID. In index.html, replace YOUR_GAMEDISTRIBUTION_GAME_ID with the ID from your GameDistribution dashboard.
4. Test ads inside GameDistribution's uploaded-game preview and enable Rewarded Ads in the dashboard. The game only counts an ad when SDK_REWARDED_WATCH_COMPLETE is received.
5. The withdrawal form is a local request/demo only. It does not transfer money. Real payouts need a secure server, eligibility/rules, and a verified payout provider.

Controls:
- FLY: click/tap the visible FLY area or press Space / Arrow Up / W
- PAUSE: click/tap the visible PAUSE area or press P
- RESTART: click/tap the visible RESTART area or press R
